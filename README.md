# skills

Custom slash commands for [Claude Code](https://claude.ai/code). Each skill is a folder with a `SKILL.md` file -- copy it into `~/.claude/commands/` and it just works.

| Skill | What it does |
|-------|-------------|
| [goal](./goal) | Set session goals from messy input, tracks them in the session log |
| [log](./log) | Writes a detailed session recap to disk so Claude remembers next time |
| [tldr](./tldr) | Prints a quick session summary + goal progress in the conversation |
| [bring-me-up-to-speed](./bring-me-up-to-speed) | Tutors you through existing work or a topic until you've demonstrably understood it |
| [seo](./seo) | SEO, accessibility, and social preview audit on any URL |
| [hackathon-radar](./hackathon-radar) | Finds open crypto/AI hackathons and suggests what to build |
| [de-slop](./de-slop) | Cleans dead code, weak types, and AI slop with 8 parallel subagents |
| [atomic-plan](./atomic-plan) | Breaks a plan into atomic steps and runs them one at a time with approval before and after each |
| [eod](./eod) | End-of-day: mines a repo's session transcripts for the transferable engineering lessons you gained, with a customizable focus lens |
| [ui-laws](./ui-laws) | Audits or designs a UI against the 30 laws of UX, one law and one fix per finding |
| [swap-profile](./swap-profile) | Moves every claude pane in a herdr tab onto another account profile, context kept, when one account hits its limit |
| [copy-writing](./copy-writing) | Sixteen rules for ad and product copy that does not read as AI-written, with a pre-delivery checklist |
| [muse](./muse) | Plans here, then hands the code, the diff read, the tests and the fixes to a free worker model through opencode |
| [app-install](./app-install) | Finds the real phones attached to this computer, pairs one over Wi-Fi when no cable is in, installs the Expo build and keeps it current |
| [pre-launch](./pre-launch) | Audits an app against a 154-item checklist before it meets a paying customer, with PASS, FAIL, UNKNOWN or N/A and repo evidence for each item |
